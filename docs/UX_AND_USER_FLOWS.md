# UX & User Flows — Sakhi Cycle

## 1. Design Direction & Aesthetic Principles
- **Color Palette**: Warm Cream (`#FFF5F7`), Vivid Rose Pink (`#EC738F`), Soft Pink (`#FFE5EC`), Deep Plum (`#38232A`), Muted Text (`#7D626C`).
- **Typography**: Dual serif (*Playfair Display*) and sans-serif (*Plus Jakarta Sans*) system.
- **Micro-Animations**: Gentle 3D floating spheres, breathwork pulse, smooth tab pill transitions.

---

## 2. Core User Flows

### Flow 1: Onboarding & Setup
```text
Landing Page (/) ──> Click "Set up my cycle" ──> Configuration Modal ──> Enter Period Start Date & Cycle Length ──> Calculate Active Phase & Cycle Day
```

### Flow 2: Daily Symptom & Mood Care Logging
```text
Cycle Page (/cycle) ──> Click "Log Daily Care" ──> Select Mood, Energy (1-5), Flow, Symptoms ──> Save ──> Update Cycle Garden Stage & Analytics
```

### Flow 3: AI Consultation & Guidance
```text
Sakhi AI (/chat) ──> View Non-Diagnostic Disclaimer ──> Click Prompt Chip / Type Query ──> Receive Empathetic Response
```

### Flow 4: Finding a Gynaecologist & Booking
```text
Doctors Directory (/doctors) ──> Search by Name/City ──> Click "Book Appointment" ──> Select Date & Time ──> Confirm
```
